# Specs Workspace

This directory keeps active specification infrastructure and current viewer/tooling artifacts.

Root contents:

- `_spec-json.schema.json`, `_spec-template.json` - current spec-json schema and template.
- `_design-template.md`, `_plan-template.md` - current design and implementation plan templates.
- `validate_spec.py` - validator for spec-json files.
- `*.architecture-view.html`, `*.architecture-view.json`, `*.metadata-view.json` - current architecture/metadata viewers that still need to be opened from this directory so the HTML can load its neighboring JSON files.

Completed bakery stage 1 artifacts are archived under `archive/sp-001-bakery-stage1/`.
